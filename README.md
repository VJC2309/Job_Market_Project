# Job Market Analysis and Salary Prediction Using Python

## 📌 Project Overview

This project analyzes job market data and predicts salaries using Python and Machine Learning.

The project uses data analysis, visualization, web scraping, and machine learning techniques to study job roles, experience levels, company locations, employment types, and salaries.

## 🎯 Objectives

- Analyze job market data using Python
- Clean and preprocess the dataset
- Identify common job roles and locations
- Analyze salary trends based on experience
- Visualize important job market patterns
- Build a machine learning model for salary prediction
- Develop an interactive Streamlit web application

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Beautiful Soup
- Requests
- Scikit-learn
- Streamlit

## 📊 Project Features

### 1. Data Collection
Job-related information is collected and prepared for analysis.

### 2. Data Cleaning
The dataset is cleaned by removing duplicate and missing records.

### 3. Data Analysis
Pandas is used to analyze:

- Job titles
- Experience levels
- Employment types
- Work models
- Company sizes
- Company locations
- Salaries

### 4. Data Visualization

The project generates graphs for:

- Top job titles
- Experience levels
- Average salary by experience
- Company size
- Company locations
- Highest-paying job roles

### 5. Salary Prediction

A **Random Forest Regression** model is used to estimate salary based on job-related information.

### 6. Streamlit Application

The project includes an interactive web application with:

- Job Market Dashboard
- Salary Prediction
